# Jornal Cultural - Entrevista sobre Chimamanda Ngozi Adichie

Uma produção audiovisual em formato de **jornal cultural**, desenvolvida para apresentar a trajetória, as ideias e a importância de **Chimamanda Ngozi Adichie**, uma das maiores vozes do feminismo contemporâneo. O projeto foi pensado com foco em organização visual, linguagem clara e navegação simples, criando uma experiência mais dinâmica para a apresentação do trabalho.

---

## Sobre o Projeto

Este projeto consiste em uma página temática no estilo de jornal, criada para acompanhar uma produção audiovisual sobre a escritora e ativista **Chimamanda Ngozi Adichie**.

A proposta foi transformar o conteúdo da apresentação em uma interface moderna e organizada, reunindo entrevista, contexto histórico, reflexões sobre feminismo e referências visuais que ajudam a tornar o trabalho mais interessante e fácil de acompanhar.

O projeto surgiu como uma forma de unir conteúdo escolar, identidade visual e linguagem jornalística em um formato mais criativo, acessível e atrativo.

---

## Funcionalidades

- Cabeçalho inspirado em jornais digitais
- Navegação temática
- Entrevista em vídeo incorporada à página
- Alternância entre tema claro e escuro
- Layout responsivo
- Interface inspirada em revistas e jornais culturais
- Organização visual voltada para apresentação de conteúdo
- Design moderno com foco na leitura
